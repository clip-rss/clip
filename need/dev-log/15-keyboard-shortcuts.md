# 阶段 15：键盘快捷键系统

## 概述
实现全局键盘快捷键，提升操作效率。

## 步骤清单

- [ ] 快捷键管理框架（统一注册/注销，防冲突）
- [ ] `Ctrl+N` / `Cmd+N`：添加订阅
- [ ] `Ctrl+Shift+I`：导入 OPML
- [ ] `Ctrl+Shift+E`：导出 OPML
- [ ] `Space`：阅读区向下翻页
- [ ] `Shift+Space`：阅读区向上翻页
- [ ] `r`：刷新当前源或全部源
- [ ] `Shift+R`：强制全量刷新
- [ ] `/`：聚焦搜索框
- [ ] `Esc`：关闭模态框 / 退出专注模式
- [ ] `Ctrl+1/2/3`：切换布局模式
- [ ] `Ctrl+Shift+F`（Cmd+Shift+F）：切换专注模式
- [ ] `J/K`：专注模式下切换上/下一篇文章
- [ ] 快捷键提示（tooltip 中显示对应快捷键）

## 验收标准
- 所有快捷键可正常触发
- 不与系统/浏览器快捷键冲突
- 模态框打开时不误触全局快捷键
