# 阶段 11：专注阅读模式

## 概述
实现全屏单栏专注阅读，包括浮动控制条、过渡动画、键盘导航。

## 步骤清单

- [ ] 专注模式状态管理（Store 中添加 focusMode 状态）
- [ ] 触发方式：工具栏按钮 / 快捷键 `Ctrl+Shift+F`（Cmd+Shift+F）
- [ ] 过渡动画（300ms ease，三栏淡化 → 全屏放大淡入）
- [ ] 全屏阅读区（隐藏顶部工具栏、侧栏、列表栏）
- [ ] 浮动控制条
  - [ ] 鼠标移到顶部 40px 区域时显示
  - [ ] 高度 44px，半透明背景 + `backdrop-blur: 12px`
  - [ ] 左部：退出按钮（← + "退出专注"）
  - [ ] 中部：文章标题（18px 加粗居中）
  - [ ] 右部：星标、标记已读、外部链接、笔记开关
  - [ ] 3 秒无操作自动隐藏
- [ ] 正文排版（最大宽 680px 居中）
- [ ] 独立阅读背景切换（纯白/纯黑/米黄 `#F5ECD7`）
- [ ] 键盘导航
  - [ ] `J/K` 或上下箭头切换上/下一篇文章
  - [ ] 切换时 200ms 交叉淡化动画
- [ ] 退出方式：Esc / 按钮 / 再次点击切换图标
- [ ] 退出后恢复三栏布局，阅读位置保留

## 验收标准
- 进入/退出专注模式过渡流畅
- 浮动控制条显隐正确
- 键盘切换文章正常
- 退出后阅读位置保持
