# 阶段 8：左侧栏 - 源与文件夹树

## 概述
实现左侧栏的 Feed 源列表、文件夹树形结构、交互操作。

## 步骤清单

- [ ] 左侧栏容器组件（背景 `--bg-primary`，内边距）
- [ ] 头部："源" 标题 + "＋" 图标按钮（添加文件夹或源）
- [ ] 文件夹树组件
  - [ ] 文件夹项（32px 高，展开箭头，文件夹图标，名称，未读计数胶囊）
  - [ ] 展开/折叠动画（箭头旋转 90°）
  - [ ] RSS 源项（32px 高，favicon 16x16，名称，未读计数胶囊）
- [ ] 未读计数胶囊样式（`--accent` 10% 背景，数字居中，0 时隐藏）
- [ ] 选中状态（`--accent` 10% 背景，左侧 3px 指示条）
- [ ] Hover 状态（`--bg-secondary` 背景）
- [ ] 右键菜单（编辑、暂停更新、删除）
- [ ] 拖拽排序（源列表项可拖拽重排和归类）
- [ ] 底部状态栏（"上次更新：X 分钟前"）
- [ ] 导入/导出 OPML 图标按钮
- [ ] 数据绑定：从 Store 加载 Feed 列表与分类
- [ ] 点击源项 → 触发中间栏文章列表更新

## 验收标准
- 树形结构正确展示，支持多级嵌套
- 展开折叠流畅，状态保持
- 未读计数实时更新
- 右键菜单功能正常
- 拖拽排序可用
