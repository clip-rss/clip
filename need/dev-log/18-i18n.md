# 阶段 18：国际化（i18n）

## 概述
实现中文/英文双语支持。

## 步骤清单

- [x] i18n 框架选型与集成（i18next + react-i18next）
- [x] 中文语言包
- [x] 英文语言包
- [x] 语言切换逻辑（设置面板 + 跟随后端 Settings.language）
- [x] 日期时间格式化本地化（相对时间通过 i18next.t() 获取）
- [x] 所有 UI 文本替换为 i18n key
- [x] 数字格式本地化（每源条目数 "N 篇" / "N items"）

## 验收标准
- 中英文切换正常，所有文本完整翻译
- 日期时间格式正确跟随语言设置
- 无硬编码中文文本
