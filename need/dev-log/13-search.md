# 阶段 13：搜索功能

## 概述
实现全文搜索，基于 SQLite FTS5，前端实时过滤。

## 步骤清单

- [ ] 搜索框聚焦交互（快捷键 `/` 聚焦）
- [ ] 前端搜索输入防抖处理（300ms）
- [ ] 后端搜索 API（标题、摘要、笔记全文检索）
- [ ] FTS5 查询优化（分词、模糊匹配）
- [ ] 搜索结果展示（中间栏列表替换为搜索结果）
- [ ] 搜索结果数量提示（"找到 X 篇文章"）
- [ ] 搜索高亮（匹配关键词高亮显示）
- [ ] 空搜索结果状态
- [ ] 搜索历史（可选，最近 5 条）
- [ ] 清除搜索恢复原列表

## 验收标准
- 搜索响应快速（<200ms 对万篇文章）
- 中英文搜索均正常
- 搜索结果正确，高亮清晰
