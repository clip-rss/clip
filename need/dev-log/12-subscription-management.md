# 阶段 12：订阅管理功能

## 概述
实现添加订阅的多种方式、订阅编辑、OPML 导入导出。

## 步骤清单

- [ ] 添加订阅模态框组件
  - [ ] 输入 RSS/Atom URL
  - [ ] URL 检测与验证（加载中状态）
  - [ ] 展示 Feed 信息预览（标题、描述、文章数）
  - [ ] 选择归属文件夹
  - [ ] 确认添加
- [ ] 网站 URL 自动发现 RSS（输入普通 URL → 解析 `<link rel="alternate">`）
- [ ] OPML 导入功能
  - [ ] 文件选择对话框
  - [ ] 解析 OPML 结构
  - [ ] 批量导入 Feed（含文件夹层级）
  - [ ] 导入进度展示
  - [ ] 重复源检测与跳过
- [ ] OPML 导出功能
  - [ ] 导出当前所有 Feed 与文件夹结构
  - [ ] 文件保存对话框
  - [ ] 可选附带阅读状态（自定义扩展）
- [ ] 编辑订阅源
  - [ ] 修改标题
  - [ ] 修改分类/文件夹
  - [ ] 设置单源更新间隔
  - [ ] 设置保留文章数量上限
- [ ] 暂停/恢复源更新
- [ ] 删除订阅源（二次确认）

## 验收标准
- 手动 URL 和网站自动发现均可正确添加订阅
- OPML 导入导出格式正确，兼容主流阅读器
- 编辑、暂停、删除功能正常
