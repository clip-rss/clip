# 阶段 6：定时调度器

## 概述
实现后台定时抓取调度，支持全局与单源更新间隔配置。

## 步骤清单

- [x] 调度器核心结构（管理多个 Feed 的更新计时）
- [x] 全局默认更新间隔配置（30 分钟，可配置 15min/30min/1h/手动）
- [x] 单源覆盖更新间隔
- [x] 智能退避机制（连续失败时指数退避，最大 24h，成功后恢复）
- [x] 并发控制（最多 5 个协程同时更新）
- [x] 手动触发单源/全部刷新接口
- [x] 强制全量刷新（忽略条件 GET）
- [x] 暂停/恢复源更新
- [x] 调度器启动/停止生命周期管理
- [x] 新文章通知事件发送（Wails Events: `items:updated`）
- [x] 单元测试：调度逻辑与退避机制

## 验收标准
- Feed 按设定间隔自动更新
- 退避机制正确工作
- 手动刷新立即触发
- 事件正确推送给前端
