# 阶段 9：中间栏 - 文章列表

## 概述
实现文章列表展示、筛选排序、虚拟滚动、批量操作。

## 步骤清单

- [ ] 文章列表容器组件（背景 `--bg-secondary`）
- [ ] 列表头部（40px）
  - [ ] 筛选下拉：全部 / 未读 / 已读 / 星标 / 今日
  - [ ] 排序按钮（时间 / 来源）
  - [ ] 批量操作 "…" 菜单（标记所有已读、批量星标）
- [ ] 文章行组件（64px 高）
  - [ ] 未读指示器：8x8 蓝色实心圆点
  - [ ] 标题：14px 加粗（未读）/ 正常（已读），单行省略
  - [ ] 摘要：12px 次级色，最多两行省略
  - [ ] 底部行：来源名 · 相对时间
  - [ ] 右侧操作图标（hover 显示）：星标、外部链接
- [ ] Hover 状态（`--bg-tertiary`）
- [ ] 选中状态（`--accent` 5% 背景，标题颜色 `--accent`）
- [ ] 星标切换交互（点击即时切换填充状态）
- [ ] 虚拟滚动实现（@tanstack/react-virtual，万级数据流畅）
- [ ] 空状态展示（插画 + "暂无未读文章"）
- [ ] 纤细滚动条样式（4px 宽）
- [ ] 点击文章 → 右侧加载正文 + 行高亮
- [ ] 自动标记已读逻辑（显示超过 2 秒 / 点击即标记）

## 验收标准
- 列表渲染流畅（万条数据无卡顿）
- 筛选排序正确切换
- 已读/未读/星标视觉状态正确
- 虚拟滚动正常工作
