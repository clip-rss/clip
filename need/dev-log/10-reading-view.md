# 阶段 10：右侧栏 - 阅读视图

## 概述
实现文章正文阅读区域，包括内容渲染、排版、工具栏、滚动位置记忆。

## 步骤清单

- [ ] 阅读视图容器组件（背景 `--bg-primary`）
- [ ] 阅读工具栏（浮动顶部，40px 高，下阴影）
  - [ ] 左部：文章标题（18px 加粗，溢出省略）
  - [ ] 右部操作：标记已读/未读、星标、笔记开关、浏览器打开、更多菜单
- [ ] 正文区域
  - [ ] 最大宽度 680px 居中，上下 24px 内边距
  - [ ] 文章大标题（24px 加粗）
  - [ ] 元数据行（作者、发布时间、来源，14px 次级色）
  - [ ] 分隔线
  - [ ] HTML 正文渲染（清除原文样式，统一排版）
- [ ] 正文排版
  - [ ] 字体切换（衬线/无衬线/等宽）
  - [ ] 字号设置（14px/16px/18px）
  - [ ] 行高设置（1.5/1.8/2.0）
  - [ ] 最大阅读宽度（640px/800px/全宽）
- [ ] 图片处理
  - [ ] 懒加载 + 灰色骨架屏占位
  - [ ] 最大宽度 100%，圆角 6px
  - [ ] 点击放大预览（灯箱效果）
- [ ] 代码块高亮（背景 `--bg-tertiary`，等宽字体）
- [ ] 链接行为：系统浏览器打开
- [ ] 纤细滚动条（4px）
- [ ] 底部 "已是全部内容" 提示
- [ ] 滚动位置记忆（切换文章时记住进度）
- [ ] 阅读区独立背景色选项（亮色/暗色/Sepia）

## 验收标准
- HTML 正文正确渲染，无 XSS 风险
- 排版设置实时生效
- 图片懒加载、放大预览正常
- 代码块有语法高亮
- 滚动位置记忆正确
