# 阶段 3：顶部全局工具栏

## 概述
实现顶部 48px 工具栏，包含窗口控制、搜索框、主题切换、添加订阅、布局切换。

## 步骤清单

- [x] 工具栏容器组件（48px，`--bg-secondary`，下边框）
- [x] macOS 红绿灯窗口控制区域占位（Windows 下为图标占位）
- [x] 搜索框组件：280px 宽，32px 高，圆角 20px，放大镜图标 + 占位文字
- [x] 搜索框 hover 状态（边框变 `--accent`）
- [x] 主题切换按钮（太阳/月亮图标 20x20，tooltip "亮色/暗色/跟随系统"）
- [x] 添加订阅按钮（`--accent` 背景，白色文字 "＋ 订阅"，32px 高）
- [x] 布局切换图标（三栏/专注模式切换，带 tooltip）
- [x] 拖拽区域设置（Wails `data-wails-drag` 属性，可拖拽窗口）

## 验收标准
- 工具栏视觉与设计稿一致
- 各按钮可点击，交互正确
- macOS/Windows 窗口控制正确显示
