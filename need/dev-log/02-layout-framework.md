# 阶段 2：三栏布局框架

## 概述
实现主界面三栏经典布局，包括可拖拽分割线、响应式栏宽调整。

## 步骤清单

- [x] 创建主布局组件 `Layout`（三栏容器）
- [x] 左侧源栏容器（默认 260px）
- [x] 中间文章列表栏容器（默认 380px）
- [x] 右侧阅读区容器（剩余空间）
- [x] 实现垂直分割线组件（1px，hover 变为拖拽手柄）
- [x] 实现拖拽调整栏宽逻辑（鼠标 col-resize 光标）
- [x] 拖拽手柄视觉：竖排三点，4x4px 圆点
- [x] 栏宽记忆持久化（存储到 localStorage，Zustand persist）
- [x] 全局顶部工具栏容器（高度 48px）

## 验收标准
- 三栏正确显示，比例正确
- 拖拽分割线可调整栏宽，有手柄提示
- 栏宽刷新后保持记忆
