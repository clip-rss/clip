# 阶段 19：性能优化与离线支持

## 概述
确保应用性能达标，实现离线阅读能力。

## 步骤清单

- [ ] 启动性能优化（<100 源时启动时间 <2s）
- [ ] 虚拟滚动优化（万级文章列表流畅）
- [ ] 内存控制（万篇文章缓存 <200MB）
- [ ] 文章正文缓存到 SQLite（离线可读）
- [ ] 图片本地缓存策略（可选）
- [ ] 离线状态检测与 UI 提示
- [ ] 离线时暂停更新定时器
- [ ] 增量加载（分页查询，避免一次加载全部数据）
- [ ] 前端内存列表优化（增量更新而非全量替换）
- [ ] 图片防盗链代理（后端缓存为 base64，可选）

## 验收标准
- 启动时间 <2s（100 源以下）
- 万级文章列表滚动 60fps
- 离线时已缓存文章可正常阅读
- 内存占用在合理范围
