## 1. 整体架构与基础要求

### 1.1 技术栈约束

- **桌面壳**：Wails v3（Go + WebView）
- **前端**：React，TypeScript，vite，pnpm，prettier
- **UI**：Tailwind CSS + 无头组件库（如 Radix UI），所有颜色使用 CSS 变量以支持亮暗切换
- **状态管理**：React Context + useReducer 或轻量库（如 Zustand），方便持久化
- **后端**：Go，负责 RSS 抓取、解析、本地存储、定时任务

### 1.2 跨平台一致性

- 窗口最小尺寸：800×600（可配置）
- macOS 下菜单栏集成（通过 Wails 菜单 API）
- Windows 下系统托盘支持（可选，作为二期）
- 所有文件路径使用 Go 的 `os.UserConfigDir` 等跨平台方法

## 2. RSS 源管理

### 2.1 订阅源（Feed）

- **添加订阅**
  - 方式一：手动输入 RSS/Atom URL
  - 方式二：从 OPML 文件导入
  - 方式三：粘贴普通网站 URL，自动发现 RSS（检查 `<link rel="alternate">`）
- **属性**
  - `id`：唯一标识
  - `url`：订阅地址
  - `title`：可手动修改
  - `description`
  - `link`：网站主页
  - `icon`：favicon 或自定义
  - `category` / `folder`：用户自定义分类或文件夹（支持嵌套，如“技术 / 前端”）
  - `updateInterval`：自定义更新间隔（默认 30 分钟，可单独设置）
  - `maxItems`：保留文章数量上限（默认无限制，可设 100/500）
  - `lastUpdated`：上次抓取时间
  - `errorCount` 与 `lastError`：用于 UI 提示
  - `status`：active / paused / error

### 2.2 文章（Item）

- **属性**
  - `id`：基于 feed URL + item guid/isPermalink 生成稳定 ID
  - `feedId`
  - `title`
  - `author`
  - `publishedAt` / `updatedAt`
  - `url`：原文链接
  - `content`：HTML 正文（清洗后）
  - `summary`：纯文本摘要（用于列表，前 200 字）
  - `enclosure`：附件（播客音频、图片等）
  - `categories`：该文章自身的标签
  - **状态标记**：
    - `isRead`：boolean
    - `isStarred`：boolean
    - `readAt`：可空时间戳（首次阅读时间）
    - `note`：用户私人笔记（纯文本，可搜索）

### 2.3 定时更新策略

- **全局默认**：30 分钟，用户可修改（15 分钟 / 30 分钟 / 1 小时 / 手动）
- **单源覆盖**：可单独设某 Feed 的更新间隔
- **智能退避**：连续失败时指数退避（最多 24 小时一次），成功后恢复
- **抓取并发控制**：最多同时 5 个协程，避免资源风暴
- **条件 GET**：使用 `ETag` / `If-Modified-Since`，减少带宽
- **去重**：新文章通过 guid + 发布时间判断，避免重复插入；如果 guid 缺失，用 link + title 组合指纹

### 2.4 数据存储

- **SQLite**（Go 侧，使用 mattn/go-sqlite3 或 [modernc.org/sqlite](https://modernc.org/sqlite)，Wails 绑定无需 CGO 可考虑纯 Go 版本）
- **表设计**
  - `feeds`
  - `items`
  - `feed_categories`（分类，可树形）
  - `item_notes`（或作为 item 的字段）
- **前端本地缓存**：通过 Wails 的 Events 实时推送增量更新，前端维护内存列表 + 虚拟滚动

## 3. 阅读体验

### 3.1 布局模式

- **三栏经典布局**（默认）：
  - 左侧：源列表 / 文件夹树（可折叠，宽 200–260px 可拖拽调整）
  - 中间：文章列表（标题、摘要、时间、已读/星标图标，宽 300–400px 可调）
  - 右侧：阅读区
- **专注阅读模式**：仅全屏文章视图，隐藏所有 chrome（快捷键 Toggle）

### 3.2 文章列表

- **视图选项**：
  - 列表视图：每行标题 + 摘要片段 + 日期 + 来源名
  - 紧凑视图：仅标题 + 日期
  - 卡片视图：大图 + 标题 + 摘要（适合科技博客）
- **排序**：按时间倒序（默认）、时间正序、按来源、按未读优先
- **筛选**：全部 / 未读 / 已读 / 星标 / 今日
- **搜索**：实时搜索文章标题、摘要、笔记，支持全文搜索（通过 SQLite FTS5）
- **批量操作**：
  - 全选可见文章
  - 标记已读/未读
  - 添加星标/取消星标
- **工具栏**：
  - 切换已读/未读
  - 切换星标
  - 在浏览器打开原文

### 3.3 阅读视图

- **内容渲染**：
  - 清洗 HTML，防止 XSS
  - 自定义 CSS 重写文章样式（字体、行高、宽度限制，图片自适应）
  - 支持 **阅读器模式**：提取正文（类似 Safari Reader），使用 `mozilla/readability` 或 Go 侧实现
- **字体设置**：
  - 可选衬线/无衬线/等宽
  - 字号：小/中/大（14px/16px/18px 基准）
  - 行高：1.5/1.8/2.0
  - 最大阅读宽度：640px / 800px / 全宽
- **图片处理**：
  - 懒加载
  - 点击放大预览（灯箱）
  - 防盗链处理：后端可缓存图片为 base64 或代理（可选）
- **内嵌视频/音频**：允许 `<video>` `<audio>`，宽度 100%
- **链接行为**：默认在系统浏览器打开
- **代码高亮**：自动识别代码块并高亮（highlight.js 按需加载）
- **滚动位置记忆**：切换文章时记住上篇的阅读进度（百分比），下次打开自动定位

### 3.4 离线支持

- 文章正文和图片缓存到本地 SQLite，离线时仍可阅读
- UI 明确显示离线状态，暂停更新定时器

## 4. 文章标记与收藏

### 4.1 已读/未读

- **标记时机**：
  - 文章在阅读区显示超过 2 秒自动标记已读（可配置延迟或关闭）
  - 鼠标点击文章行立即标记已读
- **视觉区分**：
  - 未读：标题加粗，左侧蓝色圆点指示器
  - 已读：正常字重，无圆点
- **全局操作**：
  - “标记所有为已读”按钮（需二次确认或支持撤销）
  - 按源/文件夹批量标记已读

### 4.2 星标（收藏）

- 星标文章独立视图（类似“收藏夹”）
- 星标列表支持搜索和导出（导出为 HTML 或 Markdown）

### 4.3 笔记

- 在阅读视图右侧或底部添加笔记面板
- 支持 Markdown 纯文本
- 笔记可搜索，并同步关联到文章

### 4.4 标记同步与备份

- 所有标记信息存储在 SQLite，导出 OPML 时可选附带阅读状态（自定义扩展）
- 未来可对接云同步（如 WebDAV、GitHub Gist）

## 5. 亮暗主题适配

### 5.1 色彩系统

- 使用 Tailwind 的 `darkMode: 'class'` 策略
- 定义语义化颜色 Token（如 `--color-bg-primary`, `--color-text-primary`），在亮色和暗色下分别赋值
- 至少三档主题：
  - **亮色**：高对比，纯白背景 `#FFFFFF`
  - **暗色**：深灰背景 `#1E1E1E` 或纯黑 `#121212`
  - **Sepia**（护眼）：暖黄背景 `#F5ECD7`（作为亮色变体）
- 代码块、表格、分割线在暗色下都要有合适的 contrast

### 5.2 切换方式

- 应用内开关：亮 / 暗 / 跟随系统
- 首次启动跟随系统 preference（通过 Wails 读取系统主题或前端 `matchMedia`）
- 切换无闪烁：在 React 渲染前注入 class 到 `<html>`（通过脚本或 Effect）
- 阅读区域主题独立：可让文章背景一直保持亮色/暗色，即使在 Sepia 模式下也可选择（用户可选）

### 5.3 无障碍

- 所有颜色组合满足 WCAG AA 对比度（至少 4.5:1 正文）
- 焦点指示器可见（亮色下深色边框，暗色下浅色边框）
- 提供高对比度模式选项

## 6. 交互与体验细节

### 6.1 键盘快捷键全表

| 快捷键             | 动作                    |
| :----------------- | :---------------------- |
| `Ctrl+N` / `Cmd+N` | 添加订阅                |
| `Ctrl+Shift+I`     | 导入 OPML               |
| `Ctrl+Shift+E`     | 导出 OPML               |
| `Space`            | 向下翻页（阅读区）      |

| `Shift+R`          | 强制全量刷新            |

| `Esc`              | 关闭模态 / 退出专注模式 |
| `Ctrl+1/2/3`       | 切换布局模式            |

### 6.2 拖拽操作

- 将文章拖拽到左侧文件夹可移动到该分类（仅虚拟移动，不改变真实 feed）
- 左侧源列表可通过拖拽重新排序和归类

### 6.3 通知

- 原生系统通知（通过 Wails 调用，Go 侧使用 `beeep` 或系统通知库）
- 用户可选择：每个新文章通知 / 仅摘要 / 关闭通知
- 点击通知：调起窗口并定位到该文章

### 6.4 国际化和本地化

- 初期仅支持中文、英文
- 日期格式化跟随系统 locale 或用户设置

## 7. 开发与工程细节（供实现参考）

### 7.1 Go 后端模块划分

- `cmd/app`: 应用入口，初始化 Wails
- `internal/store`: 数据库操作
- `internal/fetcher`: HTTP 抓取、RSS/Atom 解析
- `internal/scheduler`: 定时调度
- `internal/opml`: OPML 导入导出
- `internal/reader`: Readability 正文提取
- `api`: Wails 绑定的方法，暴露给前端

### 7.2 前后端通信

- 使用 Wails 的 `Bind` 方法，前端配置好 `alice` 后统一将 Go 方法导出到 `utils` 中
- 增量更新通过 Wails Events：后端有新文章时触发 `items:updated` 事件，前端合并更新
- 所有 I/O 操作用 loading 骨架屏或进度条

### 7.3 性能指标

- 订阅源数量 < 100 时，启动时间 < 2s
- 文章列表虚拟滚动（万级数据流畅，使用 `@tanstack/react-virtual`）
- 内存占用 < 200MB（万篇文章缓存）
