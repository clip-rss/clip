#### 2.1.1 添加订阅弹窗（Add Subscription Modal）

点击工具栏「＋ 订阅」按钮触发。这是一个**两阶段交互**的模态对话框：先检测订阅地址，检测成功后再填写名称并确认添加。

**遮罩层（Overlay）**

- 全屏覆盖，背景 `rgba(0,0,0,0.4)`；点击遮罩区域**不关闭**弹窗（避免误点丢失已填写内容），仅可通过关闭「✕」、「取消」按钮或 `Esc` 关闭
- 弹窗居中显示，过渡动画：150ms ease，遮罩淡入 + 弹窗轻微放大淡入（scale 0.96 → 1）

**弹窗容器（Dialog）**

- 宽度 520px，背景 `--bg-primary`，圆角 12px，阴影 `0 12px 32px rgba(0,0,0,0.18)`
- 整体由「头部 / 主体 / 底部」三段构成，头部与底部各有 `1px solid --border` 分隔线

**头部（Header，高度约 56px，内边距 20px 24px）**

- 左侧：RSS 图标（蓝色 `--accent`，约 20x20）+「添加订阅」标题（18px 加粗 `--text-primary`，与图标间距 8px）
- 右侧：关闭「✕」图标按钮（20x20，`--text-secondary`，hover 时 `--text-primary` + 背景 `--bg-secondary` 圆角）

**主体（Body，内边距 20px 24px）**

1. **订阅地址区**（始终显示）

2. **检测结果提示条**（仅检测成功后显示，image_5）
   - 上间距 16px，高度约 44px，背景 `--accent` 8% 透明，圆角 8px，内边距 12px
   - 内容：✓ 圆形勾选图标（`--accent`）+「检测成功，找到订阅源：{标题}」14px `--accent`
   - 检测失败时改为错误样式：背景 `--danger` 8%，✕ 图标 + 错误文案（如「无法解析该地址，请检查 URL」）`--danger` 文字

3. **订阅源名称区**（仅检测成功后显示，image_5）

**底部（Footer，高度约 64px，内边距 16px 24px，按钮右对齐）**

- 「添加订阅」按钮：高度 40px，圆角 8px，白色文字 14px 加粗，与「取消」间距 12px
  - **禁用态**（未检测成功，image_4）：背景 `--accent` 40% 透明（浅蓝），不可点击，cursor `not-allowed`
  - **可用态**（检测成功后，image_5）：背景 `--accent` 实心，hover 加深

**交互流程与状态机**

| 状态 | 触发 | UI 表现 |
|:-----|:-----|:--------|
| `idle` | 弹窗打开 | 仅显示地址输入区，「添加订阅」禁用 |
| `detecting` | 点击「检测」 | 「检测」按钮 loading，输入框只读 |
| `detected` | 检测成功 | 显示成功提示条 + 名称输入框（预填标题），「添加订阅」启用 |
| `error` | 检测失败 | 显示错误提示条，「添加订阅」保持禁用 |
| `submitting` | 点击「添加订阅」 | 按钮 loading，写入数据库 |
| `done` | 添加成功 | 关闭弹窗，刷新左侧栏订阅列表 |

- 修改 URL 后应重置回 `idle`（清除上一次检测结果），需重新检测
- 键盘：`Esc` 关闭弹窗；地址框内 `Enter` 等价于点击「检测」；`detected` 状态下 `Enter` 等价于「添加订阅」
- 后端依赖：「检测」调用 fetcher 抓取解析（阶段 05），经由 Wails API 绑定暴露（阶段 07）；组件实现归入订阅管理（阶段 12）

- **空状态**：列表中间显示插画（极简线条风格） + “暂无未读文章”，文字 `--text-secondary` 16px

## 三、专注阅读模式

**设计图**：![image_3](/Users/unkn0wn/Documents/wails/clip/need/image/image_3.jpg)

**触发**：点击工具栏布局切换图标，或快捷键 `Ctrl+Shift+F`（Cmd+Shift+F）。三栏布局平滑过渡为全屏单栏。

### 3.1 全局

- 整个窗口仅显示阅读区，所有 chrome 隐藏（顶部工具栏、侧栏、列表栏全部淡出）
- 背景色默认为 `--bg-primary` 或用户设定的独立阅读背景
- 过渡动画：300ms ease，原界面淡化，专注界面放大淡入

### 3.2 顶部浮动控制条

- 仅在鼠标移到顶部 40px 区域时显示（或按键调出）
- 高度 44px，背景半透明 `rgba(255,255,255,0.9)`（亮色）或 `rgba(30,30,30,0.9)`（暗色），带模糊效果 `backdrop-blur: 12px`
- 左部：退出专注模式按钮（← 图标 + “退出专注” 文字）
- 中部：文章标题（18px 加粗，居中）
- 右部：同阅读视图的操作图标（星标、标记已读、外部链接、笔记开关）
- 3秒无操作自动隐藏

### 3.3 正文排版

- 最大阅读宽度：680px，水平居中
- 字体大小、行距等保持与阅读视图相同（可独立调整）
- 背景可按用户设置展示为纯黑、纯白、米黄三种。原型可展示米黄状态（`#F5ECD7`）以示意独立阅读背景能力。
- 滚动：正文区域垂直滚动，滚动条纤细半透明，仅 hover 时可见。

### 3.4 导航

- 键盘 `J/K` 或上下箭头可切换上/下一篇文章（但界面不变，内容切换为下一篇），切换时带 200ms 交叉淡化动画。原型可标注 “按键切换文章，内容淡入淡出”。

### 3.5 退出专注

- 再次点击切换图标、按 Esc、或点击顶部 “退出专注” 按钮，界面恢复三栏布局，阅读位置保留。

## 五、附加交互原型连接点

- 点击左侧源项 → 中间栏文章列表更新为该源的文章（带筛选）
- 点击文章行 → 右侧阅读区加载正文，同时行高亮
- 点击星标图标 → 即时切换填充状态，并可在筛选 “星标” 时出现
- 添加订阅按钮 → 弹出模态框：输入 URL、检测、确认添加（此原型可另附模态框描述）
- 搜索框输入 → 实时过滤中间列表，显示结果数 “找到 5 篇文章”
- 鼠标指针 → 一律显示箭头状，除了超链接（手型）、输入框和文本选择（工字型）、控制手柄（方向箭头型或抓手型）
- 禁止用户选择 → 为了消除「网页感」，除了输入框、文本选择以外，禁用用户选择即 **user-select: none**‌
- 按钮感知 → 因为「鼠标指针」的规定，在按钮上添加 **hover **以让用户感知按钮的存在
- 提示类文案 → 所有提示类文案（如：暂无XX，请选择XX）均使用斜体
